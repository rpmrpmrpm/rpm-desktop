# Every version of the command-line tools rpm ships or runs, and of what is built into them.
# This is the only place they are written. Read by:
#   scripts/build-ffmpeg.sh                       builds ffmpeg from these sources
#   scripts/fetch-tools.sh, scripts/fetch-tools.ps1   download the published ffmpeg and fpcalc
#   scripts/fetch-angle.sh                        downloads the ANGLE pair for the Mac app
#   RPM.Desktop/RPM.Desktop.csproj                checks the binaries a build or publish ships
#   scripts/release-mac.sh, .github/workflows/release-rpm-desktop.yml   run the shipped binaries
#   .github/workflows/build-rpm-ffmpeg.yml        builds win-x64 and linux-x64, publishes the release
#   .github/workflows/deploy-rpm-cloud-api.yml    puts the linux-x64 ffmpeg in the transcoder
#   scripts/gen_credits.py                        writes these versions into the About screen
# Plain KEY=VALUE lines so bash can source it and PowerShell can split it.
