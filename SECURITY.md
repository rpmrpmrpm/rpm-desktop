# Security

## Reporting a problem

Please do not report security problems in public issues, discussions or pull requests.

Report them privately through GitHub: open the **Security** tab of the repo, choose **Report a
vulnerability** and describe the problem. Only the maintainers can see the report.

Please include:

- what the problem is and what an attacker could do with it;
- the app, version and platform;
- the steps to reproduce it, or a proof of concept.

We aim to reply within 7 days. We will tell you when a fix is released and, if you want, credit you
in the release notes.

## Scope

In scope: the code in the rpm repos, and how the apps talk to the rpm server.

Out of scope here: problems in the rpm server itself, which is not open source, and denial of
service by sending many requests. You can still report server problems in the same way, and we will
handle them.

Please do not test against other people's accounts or data, and do not run automated scans against
the rpm servers.
